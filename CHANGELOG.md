## 0.0.1

* **Initial Release:** Official production release of `horizontal_credit_card`.
* **ISO/IEC 7810 ID-1 Standard Ratio:** Classical landscape aspect ratio (1.586 : 1) tailored for horizontal payment cards.
* **Interactive 3D Perspective Physics:** Pointer drag and gyroscopic angle deflection calculated via 4x4 homogeneous transformation matrices (`Matrix4`).
* **Physical 3D Rim Thickness:** Multi-layered extruded edge rendering simulating authentic physical plastic card thickness.
* **Dynamic Specular Glare Lighting:** Ambient light reflection responding in real time to 3D tilt coordinates.
* **Holographic Security Foil Shimmer:** Multi-spectral rainbow diffraction grating with optical color shifts, supporting full-surface wash, security ribbon stripe, and compact security badge layouts.
* **Dynamic Rolling CVV:** Automated 60-second rolling security code with an animated countdown circular progress ring and tap-to-regenerate support.
* **Quick-Copy Card Number Button:** Subtle one-touch copy button beside digits with animated checkmark feedback, whitespace sanitization, and callback hooks.
* **Tactile Typography Relief:** Physical 3D letterpress embossed typography finish, hot-stamped gold foil, liquid silver foil, and crisp digital printing.
* **180° Perspective Flip:** Hardware-accelerated 3D flip animation displaying magnetic stripe, signature strip, and CVV on the reverse face.
* **Sensitive Data Protection:** Tap-to-reveal privacy masking for 16-digit card numbers and CVV codes.
* **Financial Security States:** Built-in frosted ice overlay with padlock for `isFrozen` cards and official warning stamp for `isExpired`.
* **Curated Presets Library (`CardPresets`):** Ready-to-use themes across Geometric Patterns, Minimalist Solid Colors, and Luxury Metals collections.
* **Interactive 3D Web Playground:** Full Flutter Web support with live browser demonstration.
* **Zero External Dependencies:** Built 100% on the core Flutter SDK for maximum enterprise compliance, rock-solid stability, and 120 FPS performance.
